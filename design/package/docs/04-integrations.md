# 04. Интеграции и техника

## Рекомендуемый стек

- **Astro** (статическая сборка) + content collections на JSON/Markdown из `data/`. Почему: сайт почти целиком статический, Astro отдаёт чистый HTML без лишнего JS — быстро грузится с телефона из Telegram. Интерактив (отсчёт, фильтры, лайтбокс, сортировка таблиц, вкладки) — маленькие «острова» на чистом TS или Preact.
- Альтернатива: Next.js (static export), если удобнее React целиком.
- **Шрифты:** self-host через `@fontsource/oswald` и `@fontsource/manrope` (Google Fonts из РФ может грузиться нестабильно).
- **Картинки:** `astro:assets` / `sharp` → WebP/AVIF, размеры 400 / 800 / 1600, `loading="lazy"`.

## Хостинг

Статика кладётся куда угодно. Варианты с учётом аудитории в РФ:
- **Yandex Cloud Object Storage + CDN** — стабильно в РФ, дёшево.
- **GitHub Pages / Netlify / Vercel** — просто, но доступность из РФ может плавать; проверить с мобильных операторов.
- Домен — через reg.ru / nic.ru.
- Деплой: GitHub Actions по пушу в `main` (сборка → загрузка в бакет).

## Обновление данных

Минимум: правка JSON в репозитории (можно прямо в веб-интерфейсе GitHub) → автодеплой.
Удобнее для команды (позже): Decap CMS / Keystatic поверх того же репозитория — формы для «добавить матч», «добавить новость» без JSON руками.

## Таблица ЛФЛ и календарь

lfl.ru и join.football запрещают автоматический сбор данных (robots.txt). Поэтому:
- таблица и календарь ЛФЛ — **вручную** в `standings.json` / `matches.json` после каждого тура (2–3 минуты);
- в `standings.json` хранить `updatedAt` и показывать «обновлено 12 октября» под таблицей;
- ссылка «Полная таблица» → страница команды на lfl.ru.

## Бауманская лига (фэнтази) — iframe

```html
<iframe
  src="https://bauman_league.join.football/team/1089660"
  title="Бауманская лига — таблица и туры"
  loading="lazy"
  style="width:100%;height:640px;border:0"
  referrerpolicy="no-referrer-when-downgrade"></iframe>
```

**Проверить до реализации:** разрешает ли join.football встраивание. Открыть страницу лиги, в DevTools → Network → заголовки ответа:
- `X-Frame-Options: DENY` или `SAMEORIGIN` → встроить **нельзя**;
- `Content-Security-Policy: frame-ancestors …` без вашего домена → **нельзя**.

**Fallback**, если встраивание запрещено: вместо iframe — карточка «Таблица лиги на join.football» с кнопкой «Открыть ↗» и вручную поддерживаемым топ-5 в `fantasy.json`. Компонент сделать так, чтобы переключался флагом `fantasy.embed: true | false`.

Также учесть: в адресе поддомена есть `_` (`bauman_league`) — некоторые браузеры/прокси спотыкаются на подчёркивании в hostname. Проверить в Safari iOS.

## Трансляции и видео

- **VK Видео:** embed-ссылка вида `https://vk.com/video_ext.php?oid=-<group>&id=<video>&hd=2` (берётся в VK: «Поделиться» → «Экспортировать» → код). В iframe `allow="autoplay; encrypted-media; fullscreen; picture-in-picture"`.
- **YouTube:** `https://www.youtube-nocookie.com/embed/<id>`.
- **Плашка LIVE:** показывать, если матч `status = "live"` и есть `streamUrl`. Статус переключается руками в JSON перед матчем (или по времени: `kickoff ≤ now ≤ kickoff + 2ч` и есть `streamUrl` — вычислять на клиенте).
- Лёгкий плеер: до клика показывать превью + кнопку Play, iframe подставлять по клику (экономит трафик на телефоне).

## Посты из соцсетей

- **Вручную (MVP):** запись в `news.json` с `tag: "social"` и `source.url`.
- **Telegram (позже):** официальный виджет поста — `<script async src="https://telegram.org/js/telegram-widget.js?22" data-telegram-post="channel/123" data-width="100%"></script>`. Для автоимпорта — бот-админ в канале + серверная функция, которая по `channel_post` пишет новость в репозиторий через GitHub API.
- **VK:** API `wall.get` с сервисным ключом приложения, раз в N часов по cron (GitHub Actions) → `news.json` → пересборка.

## Фото

1. Выгрузить лучшие фото из Яндекс Диска (структура альбомов как в архиве: Матчи, Зимний турнир 2022, Тимбилдинги, Персональные фото).
2. Скрипт `scripts/import-photos.ts`: ресайз в 400/800/1600 WebP, генерация `media.json` (src, w, h).
3. Оригиналы не хранить в репозитории — только в Диске; «Скачать оригинал» в лайтбоксе ведёт на публичную ссылку Диска.

## Форма «Хочу в команду»

Без бэкенда не обойтись, варианты по простоте:
1. **Только ссылка** на Telegram капитана (уже есть в макете кнопкой «Написать капитану») — для MVP достаточно.
2. **Форма → Telegram-бот:** серверная функция (Yandex Cloud Functions / Netlify Functions) принимает POST и шлёт сообщение капитану через Bot API `sendMessage`. Защита: honeypot-поле + ограничение частоты.
3. **Яндекс Формы** — встроить iframe, ответы в таблицу.

## Голосование «Лучший игрок матча»

- Простой вариант: итог выбирает капитан, на сайте только результат.
- Живой вариант: та же серверная функция + KV-хранилище (Yandex YDB / Upstash Redis), один голос на устройство (cookie + IP-лимит). Голосование открыто 48 часов после матча.

## Обратный отсчёт

Клиентский скрипт, время матча из `kickoff` (ISO с `+03:00`). Обновление раз в 60 секунд. Склонение: 1 день / 2 дня / 5 дней, 1 час / 2 часа / 5 часов, 1 минута / 2 минуты / 5 минут. После начала — «Матч идёт», после `+2ч` — скрыть блок до следующего матча.

## SEO и шаринг

- `<title>` и `description` на каждой странице, `lang="ru"`.
- Open Graph: для матча — генерировать картинку 1200×630 (табло: гербы + счёт, ч/б) через `satori` при сборке — красиво разлетается в Telegram/VK.
- `schema.org/SportsTeam` на главной, `SportsEvent` на странице матча.
- Фавикон — герб.
