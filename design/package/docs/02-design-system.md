# 02. Дизайн-система

Наглядно — артборд «Дизайн-система» (`design/artboards/Kit.dc.html`). Машиночитаемо — `design/tokens.json` и `design/tokens.css`.

## Принципы

1. **Только чёрное и белое.** Серые — служебные (линии, подписи, ничья). Никаких цветных акцентов, градиентов-заливок, эмодзи.
2. **Контраст секций.** Страница — чередование чёрных и белых полос-секций, как форма.
3. **Цифры — герои.** Счёт, номера, статистика — Oswald 700, крупно.
4. **Острые углы.** `border-radius: 0` везде, кроме круглых элементов (бейджи формы, игроки на схеме, точки LIVE и таймлайна).
5. **Реальные фото** вместо стоков.

Подключение: `https://fonts.googleapis.com/css2?family=Oswald:wght@400;500;600;700&family=Manrope:wght@400;500;600;700&display=swap` (или self-host через `@fontsource`, чтобы не зависеть от Google в РФ).

| Роль | Шрифт | Размер / начертание |
|---|---|---|
| Hero-заголовок | Oswald 700, капс | `clamp(56px, 10vw, 144px)`, line-height .9 |
| H1 страницы | Oswald 700, капс | 72px (профиль/история — 104px), mobile 44–64px |
| H2 секции | Oswald 700, капс | 40px (mobile 28px) |
| H3 карточки | Oswald 600, капс | 20–24px |
| Счёт крупный | Oswald 700 | 160px (матч), 64px (карточка), mobile ×0.6 |
| Метки, кнопки, меню | Oswald 500–600, капс, letter-spacing .06–.1em | 13–16px |
| Текст | Manrope 400 | 16–18px, line-height 1.55–1.65 |
| Подписи | Manrope 400–500 | 12–14px; надзаголовки — капс, letter-spacing .1em |

## Отступы и сетка

- Шаг 4px. Частые: 8, 12, 16, 20, 24, 32, 48, 56, 64, 72.
- Контейнер: `max-width: 1280px; padding: 0 32px` (mobile 16px).
- Вертикальный ритм секций: `padding: 56–64px 0` (mobile 32px).
- Зазоры сеток: 24px (карточки), 8–12px (фото), 2px (плитки статистики через фон-подложку).

## Компоненты

### Кнопки
| Вариант | Стиль |
|---|---|
| Primary на чёрном | фон `#FFF`, текст `#0A0A0A`, Oswald 600 15px капс, padding 14×22 |
| Primary на белом | фон `#0A0A0A`, текст `#FFF` |
| Secondary | прозрачный, рамка 1–2px цвета текста |
| Фильтр-переключатель | высота 44, padding 0 18; выкл — рамка `#404040`; вкл — белая заливка, `aria-pressed="true"` |
| Иконочная | 44×44, рамка `#333`, `aria-label` |

Ховер: на чёрном фоне — инверсия (белая кнопка → `#D4D4D4`; контурная → белая заливка). Фокус: `outline: 2px solid currentColor; outline-offset: 3px`.

### Бейдж формы В / Н / П
Круг 52px (mobile 44), Oswald 700 20px.
- **В** — фон `#FFF`, текст `#0A0A0A`
- **Н** — фон `#5C5C5C`, текст `#FFF`
- **П** — прозрачный, рамка 2px `#FFF`
`title`/`aria-label`: «Победа 3:1 vs Энергия».

### Бейдж счёта (таблица результатов)
min-width 64px, Oswald 700 20px; те же три варианта, что у формы.

### Плашка LIVE
Белый фон, чёрный текст Oswald 700 14px, letter-spacing .1em, слева точка 8px. Точка пульсирует (opacity 1 → .3, 1.2s), кроме `prefers-reduced-motion`.

### Тег новости
Oswald 12–13px капс, padding 3×8. Матч/Клуб/Трансфер/Фэнтази — заливка (чёрная на белом фоне и наоборот). Пост из соцсети — только рамка 1.5px + название платформы.

### Обратный отсчёт
Блоки min-width 56px, фон контрастный секции, число Oswald 700 40px, подпись 11px капс (дня/часов/минут — склонять!). `role="timer"`, `aria-label` с полным текстом.

### Карточка матча
Белая (на чёрной странице): шапка «ТУРНИР · ТУР» + дата; гербы и названия; счёт в чёрной плашке 48px; низ — авторы голов + «Отчёт →».

### Карточка игрока
Рамка `#333`; фото 4:5 со штриховкой/фото; номер-«водяной знак» 80–96px opacity .18–.22; низ — имя Oswald 20px, подпись, номер 32px справа.

### Карточка новости
Обложка 4:3; тег + дата; заголовок Oswald 600 22px капс.

### Строка таблицы
Обычная — граница снизу `#262626`. Наша команда — белая заливка, чёрный жирный текст.

### Схема поля (8×8)
Фон — горизонтальные полосы `#141414/#101010` по 60px, рамка 2px белая, линии `#5C5C5C` 2px (средняя линия, центральный круг 22% ширины, штрафные 56% × 15%). Игрок — белый круг 40px с номером Oswald 17px + фамилия 12px на чёрной подложке.

### Герб
`assets/crest-placeholder.svg` — щит с тремя вертикальными полосами и «БЮ». Две версии: на чёрном (обводка белая) и на белом (инверсия). Заменить на настоящий герб, сохранив две версии.

### Плейсхолдер фото
`.ph` — `repeating-linear-gradient(135deg, #1C1C1C 0 14px, #161616 14px 28px)`; `.phl` (на белом) — `#E6E6E6 / #DCDCDC`.
