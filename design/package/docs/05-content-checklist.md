# 05. Что собрать перед запуском

Всё, что в макетах стоит в квадратных скобках `[…]` или придумано как заглушка.

## Обязательно для MVP

- [ ] **Герб** в векторе (SVG): версия на чёрном и на белом
- [ ] **Год основания** клуба
- [ ] **Слоган / подзаголовок** для hero (сейчас: «Футбольная команда МГТУ им. Н. Э. Баумана. Играем в ЛФЛ…»)
- [ ] **Командное фото** для hero — горизонтальное, ≥ 2400px по ширине, с запасом сверху (текст ложится на нижнюю треть)
- [ ] **Состав:** имя, фамилия, номер, позиция, прозвище, факультет, год прихода, рабочая нога, интересный факт, портрет (вертикальный 4:5, однотонный фон — лучше снять всех в один день)
- [ ] **Штаб:** капитан/менеджер, тренер, медиа — имена и фото
- [ ] **Календарь сезона** ЛФЛ: даты, соперники, стадионы, адреса
- [ ] **Результаты** сыгранных матчей сезона: счёт, авторы голов и ассистов с минутами (хотя бы голы)
- [ ] **Таблица ЛФЛ** текущего сезона
- [ ] **Соцсети:** ссылки на Telegram, VK, YouTube, страницу команды в ЛФЛ
- [ ] **Контакты:** Telegram капитана, почта
- [ ] **Тренировки:** дни, время, место (+ ссылка на Яндекс Карты)
- [ ] **Кого ищем** сейчас
- [ ] 3–5 первых новостей

## Для v2

- [ ] **История:** ключевые события по годам (основание, первый матч, заявка в ЛФЛ, трофеи) + фото к каждому
- [ ] **Трофеи и места:** турнир, сезон, место, фото кубка
- [ ] **Легенды и выпускники:** имя, годы, чем запомнился, фото
- [ ] **Статистика прошлых сезонов** — если есть таблица; если нет — хотя бы итоговые места и счёт по матчам
- [ ] **Фото из архива:** 10–20 лучших для разделов + альбомы (Матчи, Зимний турнир 2022, Тимбилдинги, Персональные)

## Для v3

- [ ] Ссылки на записи трансляций (VK Видео / YouTube)
- [ ] Стартовые составы и замены по матчам (для схемы поля)
- [ ] Правила Бауманской лиги: состав, бюджет, начисление очков, призы
- [ ] Проверить, разрешает ли join.football встраивание (см. `04-integrations.md`)
- [ ] Решение по голосованию MVP: капитан выбирает или болельщики голосуют

## Решения, которые нужно принять

- [ ] Домен (например, `baumanunited.ru`)
- [ ] Хостинг (см. `04-integrations.md`)
- [ ] Кто обновляет данные после матча и как (JSON в GitHub или CMS)
- [ ] Согласие игроков на публикацию фото и имён
