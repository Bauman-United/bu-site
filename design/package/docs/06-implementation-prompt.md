# 06. Промпт для Claude Code

Положи содержимое архива в корень пустой папки, открой там Claude Code и вставь текст ниже.

---

Сверстай и собери сайт футбольной команды «Бауман Юнайтед» по пакету в этой папке.

**Прочитай сначала, по порядку:**
1. `README.md`
2. `docs/01-spec.md` — страницы и блоки
3. `docs/02-design-system.md` + `design/tokens.css` — стили
4. `docs/03-data-model.md` + `data/*.json` — данные
5. `docs/04-integrations.md` — стек, iframe, видео, форма

Макеты лежат в `design/artboards/*.dc.html`. Это не готовый HTML, а исходники дизайн-холста: внутри `<x-dc>` обычная разметка с inline-стилями, `{{…}}` — подстановки из скрипта внизу файла, `<sc-for>` — цикл, `<sc-if>` — условие. Используй их как точный справочник по структуре, размерам, отступам и текстам; при расхождении с `01-spec.md` приоритет у макета по внешнему виду и у спеки по поведению.

**Стек:** Astro (последняя версия), TypeScript, без UI-фреймворков. Стили — один глобальный CSS на токенах из `design/tokens.css` + scoped-стили компонентов. Шрифты — `@fontsource/oswald`, `@fontsource/manrope`. Интерактив — маленькие скрипты-острова на чистом TS.

**Порядок работы:**
1. Инициализируй проект, перенеси `data/` в content collections с zod-схемами по `03-data-model.md`.
2. Напиши `src/lib/stats.ts` — все вычисления из раздела «Вычисления при сборке» с юнит-тестами (vitest) на данных из `data/`.
3. Сделай компоненты из `02-design-system.md` (Header, MobileMenu, Footer, Stripes, Crest, Button, FormBadge, ScoreBadge, LivePill, Countdown, MatchCard, PlayerCard, NewsCard, StandingsTable, Pitch, Lightbox, PhotoPlaceholder).
4. Собери страницы этапа **MVP** из `01-spec.md`: `/`, `/matches`, `/matches/[id]` (упрощённо), `/team`, `/team/[slug]`, `/news`, `/news/[slug]`, `/join`. Покажи мне результат.
5. Затем v2 (`/stats`, `/history`, `/media`), затем v3 (полная страница матча, видео, `/league` с iframe и fallback по флагу `fantasy.embed`).

**Требования:**
- Mobile-first, проверь каждую страницу на ширине 375px и 1440px.
- Только чёрно-белая палитра из токенов; никаких новых цветов, скруглений и эмодзи.
- Доступность из раздела «Доступность» в `01-spec.md` обязательна.
- Даты и время — по Москве, формат «Сб, 18 октября · 14:00»; склонения числительных правильные.
- Если поле в данных пустое — блок скрывается, а не показывает пустоту.
- Lighthouse mobile: Performance ≥ 90, Accessibility ≥ 95.
- В конце — `README` проекта: как запустить, как добавить матч / игрока / новость, как задеплоить.
