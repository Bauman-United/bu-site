# Бауман Юнайтед — пакет для реализации сайта

Всё, что нужно, чтобы сверстать и запустить сайт любительской футбольной команды «Бауман Юнайтед» (МГТУ им. Н. Э. Баумана, ЛФЛ, формат 8×8).

Макеты живут на дизайн-холсте в Claude (артефакт «Бауман Юнайтед — сайт»). Здесь — всё остальное: ТЗ, токены, данные, интеграции.

## Что внутри

| Путь | Что это |
|---|---|
| `docs/01-spec.md` | ТЗ: карта сайта, каждая страница по блокам, состояния, адаптив, этапы |
| `docs/02-design-system.md` | Дизайн-система: цвета, шрифты, отступы, все компоненты с точными стилями |
| `docs/03-data-model.md` | Модель данных: сущности, поля, как считается статистика |

| `design/tokens.json`, `design/tokens.css` | Дизайн-токены (цвета, шрифты, размеры) |

## Быстрый старт

1. Прочитай `docs/01-spec.md` и `docs/02-design-system.md`.
2. Заполни `data/*.json` реальными данными (чеклист — `docs/05-content-checklist.md`).
3. Открой Claude Code в пустой папке, положи туда содержимое архива и вставь промпт из `docs/06-implementation-prompt.md`.

## Ключевые решения

- **Стиль:** строго чёрно-белый, без цветовых акцентов. Исходы матчей различаются заливкой: победа — белая, ничья — серая `#5C5C5C`, поражение — контур.
- **Шрифты:** Oswald (цифры, заголовки, капс), Manrope (текст). Оба с кириллицей, Google Fonts.
- **Формат игры:** 8×8, базовая схема 3-3-1.
- **Mobile-first:** основной трафик из Telegram и VK с телефона.
- **Данные в JSON:** обновление без правок вёрстки. Таблица ЛФЛ — вручную (lfl.ru не отдаёт данные роботам).
- **Стек (рекомендация):** Astro + JSON content collections, статическая сборка. Подробнее — `docs/04-integrations.md`.
