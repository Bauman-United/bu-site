# Макеты

Живой холст — артефакт «Бауман Юнайтед — сайт» в Claude (там можно листать, комментировать и запускать Play с переходами между страницами).

`artboards/` — исходники каждого артборда. Формат `.dc.html`: внутри `<x-dc>` обычная разметка с inline-стилями; `{{…}}` — подстановки из `renderVals()` в скрипте внизу файла; `<sc-for list="{{x}}" as="y">` — цикл; `<sc-if value="{{x}}">` — условие. В браузере напрямую не откроются (нужен рантайм холста) — читать как исходный код.
